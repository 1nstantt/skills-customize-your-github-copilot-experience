# 📘 Assignment: Python Functions & File I/O Challenge

## 🎯 Objective

Practice writing reusable Python functions and reading from or writing to files by building a small program that processes text data and produces a summary report.

## 📝 Tasks

### 🛠️ Read and Process Text Data

#### Description
Create a script that reads a text file containing a list of words, numbers, or short lines and processes the data using functions.

#### Requirements
Completed program should:

- Read data from a text file using Python file I/O
- Define one or more functions to process the contents
- Handle the input in a clean, reusable way
- Print or return a clear result based on the file contents

### 🛠️ Build Summary Logic

#### Description
Use functions to calculate a summary from the file contents, such as total words, average values, or item counts.

#### Requirements
Completed program should:

- Count or summarize data using Python logic
- Write the result to a new output file or print it in a readable format
- Use clear function names that explain the task they perform
- Avoid repeating code in multiple places

### 🛠️ Improve Readability and Error Handling

#### Description
Make the program easier to understand and more robust by adding helpful structure and basic validation.

#### Requirements
Completed program should:

- Include comments where they help explain the code
- Check whether the input file exists before reading it
- Display a helpful message if the file cannot be opened
- Keep the program organized with small, focused functions

## 🧠 Skills Practiced

- Writing reusable functions
- Reading and writing files in Python
- Processing text-based data
- Handling simple input validation
- Creating readable, maintainable scripts
