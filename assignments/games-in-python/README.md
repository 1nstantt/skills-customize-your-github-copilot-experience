# 🎮 Assignment: Hangman Game Challenge

## 🎯 Objective

Create a text-based Hangman game in Python that uses strings, loops, conditionals, and user input to let a player guess a hidden word before running out of attempts.

## 📝 Tasks

### 🛠️ Build the Game Logic

#### Description
Create the core gameplay loop for a Hangman game. Players should choose one letter at a time and see how their guesses affect the hidden word.

#### Requirements
Completed program should:

- Randomly choose a word from a predefined list
- Display the current word state using underscores or revealed letters
- Accept single-letter guesses from the player
- Track guessed letters and prevent repeated guesses
- Reduce the number of remaining attempts after incorrect guesses
- End the game when the player wins or runs out of attempts

### 🛠️ Add Game Feedback and End Conditions

#### Description
Improve the player experience by showing helpful messages and ending the game clearly when the round is complete.

#### Requirements
Completed program should:

- Display a message for correct and incorrect guesses
- Show the updated word after each guess
- Announce when the player has won or lost
- Reveal the secret word at the end of the game
- Use clear, readable output formatting for the user

### 🛠️ Practice Good Programming Habits

#### Description
Refine your solution so it is easier to understand, debug, and extend.

#### Requirements
Completed program should:

- Use meaningful variable names
- Keep the game logic organized into small, readable sections
- Avoid repeated or unnecessary code
- Include comments where they help explain the program
- Run without crashing when the player enters invalid input
